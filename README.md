☕ Cafe Website
A simple and responsive Cafe Website built using HTML, CSS, and JavaScript. The website displays the cafe menu, allows users to add items to a cart, and includes a contact form for customer queries or feedback.

🚀 Features
🍽️ Menu Section – Displays cafe food and beverages with prices
🛒 Add to Cart Functionality – Add and remove items from the cart dynamically
📩 Contact Form – Users can submit queries or feedback
📱 Responsive Design – Works on desktop, tablet, and mobile
🎨 Clean UI – Simple and attractive cafe-themed design
⚡ Client-Side Functionality – Powered entirely by JavaScript

🛠️ Technologies Used

HTML5 – Structure of the website
CSS3 – Styling and responsive layout
JavaScript (Vanilla JS) – Cart logic and form handling
